# 模型菜单内项目选择：设计确认

## 范围与状态

本轮用户要求移除输入框附近的独立项目面板，将选择项目功能放到模型服务商列表的Collaboration位置，并用展开列表时重新获取项目代替刷新按钮。用户已完成钉钉扫码，并要求暂不验证Codego或服务器模型交互。用户已明确确认Q1—Q13并授权按最终方案开始实现。此前两轮按推荐确认；最后回复为“Q10–Q13按推荐，按Q1–Q13最终方案开始实现。”

不使用subagent或workflow；实施仅修改此客户端源码、测试和文档并交付本地包，不修改现用GUI/profile／成员配置／服务器，不调用真实模型、不重发截图中的失败消息。所引用会话快照只有三条用户“你好”，不包含可独立核验的远端错误原因。

## 第一轮已确认：Q1—Q4

- Q1：移除当前Collaboration组下单独“项目选择”项，直接列出服务器返回的可访问项目，显示项目标识／名称并参与菜单搜索；不增加项目子菜单，不保留输入框附近的独立面板。
- Q2：点击项目即完成当前会话的项目选择并启用协作路由，不再单独确认。尚未建立远端对话时允许重新选择；已有远端对话时不允许换项目，业务执行中不允许切换。选择本身不创建远端业务对话、不发送消息，只有用户随后主动提交新指令才执行业务。
- Q3：模型服务商／模型列表实际展开时刷新授权项目，每次关闭后重新展开获取一次；搜索、鼠标移动、重绘不重复请求，没有菜单时不轮询。只核验身份／读取项目，不调用Codego、不自动扫码；无单独刷新按钮。
- Q4：未登录、加载中、无可访问项目或错误只显示在Collaboration分组，不阻塞普通模型选择。失败时不允许旧缓存用于新项目选择；既有归属不自动清空、替换或迁移，重开列表重试。

## 已核对的事实

当前成员Host只广告一个固定协作路由，项目选择独立保存在当前本地对话的成员／服务归属中；创建远端对话后不能换项目。官方模型选择器每次打开会调用load，但共享目录load缓存Host代目录；不能只把项目塞进listModels便声称每次展开已刷新。

固定官方DSH0.2.0-rc.2模型菜单未提供项目专用行或展开回调子槽；会话模型位置是支持优先级接替的single槽。实施应优先使用公开扩展／数据服务，保留普通模型功能及组件卸载回退，不能通过DOM文本匹配或直接修改安装的官方文件实现。Q10已确认通过single槽优先级接替模型位置，普通模型走原目录服务；具体实现与兼容限制见[菜单指南](<PROJECT-MENU.md>)，不对现用GUI静默改动。

官方会话selectModel会在设置会话选择后异步保存默认模型，而项目选择是当前对话专属，不能把项目归属泄漏为新会话默认项目。点击项目同时更新项目选择和协作路由涉及失败一致性，不能用两个无保护请求假称全部成功。

## 第二轮已确认：Q5—Q9

- Q5：成功选择后，输入框模型位置显示项目标识与名称；二者相同则简化，长名称截断并提供完整悬停信息。菜单对应项目打勾；普通模型保持自己的名称。
- Q6：已有远端对话时仍刷新显示最新授权项目，但除原项目外其他项目不可选，并提示换项目需新建会话。允许主动切回普通模型；返回协作只能回到原项目，不清除绑定、不重发旧消息。忙时所有相关切换仍禁止。
- Q7：新本地对话不自动继承上一会话的项目，只有一个授权项目也必须明确点选；模型偏好不成为项目默认值。
- Q8：项目改名按最新名称显示，但归属依据稳定项目ID；原项目被撤权／删除时保留原归属记录并显示不可访问，不能再次选择或自动换项目；网络查询失败明确区分，不推断项目被删除。
- Q9：项目选择与当前协作路由一起成功才发布新的勾选／成功状态。确定失败保持原有效选择、菜单内提示并保持打开、不发消息或自动重试；结果未知时明确未确认，重新读取状态后才能继续选择。不能用两个无保护请求假称完成。

## 第三轮已确认：Q10—Q13

- Q10：通过公开single槽优先级机制接替模型位置，只替换Collaboration内容；保留普通模型分组、搜索、推理等级、键盘操作。禁用／卸载恢复官方菜单，不修改DSH安装目录。协作选择仅当前会话，不写全局默认项目或协作模型默认。
- Q11：关闭／重开、快速点击和会话切换时过期查询不得跨会话／成员发布，选择中防重复；已提交选择不能因关闭菜单被误判撤销，返回后读取真实状态。身份／配置改变使旧查询不可用于选择。
- Q12：不新增/project、设置页项目入口或其他面板；普通/model保持原行为。旧协作路由没有明确项目时提示回菜单，不能自动绑定或绕过执行业务的项目保护。
- Q13：覆盖菜单UI、每次展开刷新、锁定、登录／撤权／查询失败／选择未知、会话隔离、普通功能及卸载回退，再抽取包重测；本地包交付，不调用Codego／真实模型，不代安装到现用GUI或修改真实配置／服务器。
