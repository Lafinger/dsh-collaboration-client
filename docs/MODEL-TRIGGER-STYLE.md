# 0.5.2：会话模型按钮恢复原生样式

## 范围

会话输入框右下角模型触发按钮恢复DSH0.2.0-rc.2原生视觉；不撤回Collaboration项目菜单，不把业务项目变成底层模型，也不恢复旧版单个“项目选择”菜单。项目展开刷新、点选绑定、未知状态、普通模型／推理等级和0.5.1的Remote依赖修复保留，Host运行源码、协议和数据库流程没有改变。

[按钮实现](<../client/model-menu.js>)采用原生13px字号／20px行高／400字重、28px高度、4px间距与相同内边距；模型名称和推理等级分开，后者使用caption色并优先收缩。长名称保留截断和完整title，普通模型title包含推理等级；项目只显示项目标签，不附加普通模型的等级。箭头和紧凑图标使用共享IconChevronDownOutlineRegular／IconDataOutlineRegular，忙碌时使用共享StateDot而非文本字符，展开时箭头旋转。跟随composer的文字／图标切换变量；键盘聚焦使用原生外侧box-shadow，选择后恢复焦点时暂不画焦点环，失焦或重开后恢复。

[浏览器入口](<../client/index.js>)只从静态共享ui-primitives获取图标；不导入官方feature组件、不借用构建散列类名、不读取或改写现用DOM。展开菜单的项目行／搜索区布局不在本次外观调整范围内。

## 验证

[样式回归](<../test/model-trigger-style.test.mjs>)加载固定官方模型选择构件的实际CSS，与重建插件逐项比较按钮、独立名称／推理等级、窄屏图标、展开箭头和focus样式。原0.5.1构建在min-width及缺少独立样式处先失败，恢复后通过；原生构建将透明背景压缩为0 0，比较时仅统一该等价写法，不忽略字体、尺寸或颜色差异。

[完整菜单链路](<../test/official-model-project.integration.mjs>)断言按钮分别呈现模型／High、使用共享图标、展开旋转、忙碌指示、选中项目后不残留推理等级，同时覆盖刷新、授权变化、提交未知、会话隔离、普通模型和卸载／再加载。[依赖回归](<../test/menu-runtime-composition.integration.mjs>)仍检查真实Loader和可追踪Remote Service，不允许项目菜单崩溃退位。

离线浏览器对比页由固定官方组件和重建插件实际渲染，并用现用安装中只读提取的共享SVG截图核对普通／紧凑模式；不是手绘参考图，也不是现用DSH窗口验收。测试不使用现用登录或成员库；最终数量和包hash见本次交付说明。

## 安装后只核对外观

1. 使用0.5.2本地包升级，刷新原页面；若宿主要求重启，则退出重开后再刷新。没有经验证的构建watcher，不能承诺源文件修改自动更新现用窗口。
2. 保持截图中同一普通模型／High，检查右下角字号、次级色、间距及小箭头；悬停检查完整名称和等级。缩窄窗口时按钮应跟随原生composer切为图标。
3. 可展开模型列表确认Collaboration仍直接列项目，选择项目后显示其名称。不要发送消息或调用模型来验证外观；无需改成员JSON、profile、清库或重新绑定旧远端会话。

本轮不代装或刷新现用GUI、不修改DSH安装、服务器或真实库，不调用SSH、扫码、Codego、模型或业务消息。Host重启使内存登录失效时按设置页状态重新扫码，不把样式变化解释为权限变化。0.5.0依赖故障另见[修复记录](<MENU-INJECT-FIX.md>)。
