# 0.6.3-rc.9：组织资格、成员姓名和职责展示

配套服务端0.7.2-rc.11。角色候选展示服务端核验资格与时间，仅允许assignable成员被选择；未知、失效和需重新登录与空缺分开，保留已有职责的姓名及待重新分配提示。同名成员按非敏感短标记区分，不按姓名合并。

手动刷新时显示加载，失败时保留明确标注的旧快照但锁定提交、清空旧候选选择，不把失败当作同步成功。服务端暂时组织核验失败保留尚有效的本地登录但提示暂停，不续登录期限。

通过与当前账号/服务一致的已认证whoami更新本人显示姓名及加密登录快照，仅采纳展示字段，不替换令牌、设备、到期或身份代次，也不重放业务/切换项目。

保持协作4／附件2／人类授权3。连接旧服务端时明确提示缺少组织同步展示，不假称已经同步；完整能力需要服务端rc.11。用户自行安装固定源：
