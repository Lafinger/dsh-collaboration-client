
发行状态及三份已验证资产以[该tag的GitHub Release](<https://github.com/Lafinger/dsh-collaboration-client/releases/tag/v0.6.2-rc.1>)与对应Actions为准；发布不代替用户安装。原0.6.1-rc.1和更早tag／资产不移动、不覆盖。本插件只向GitHub发行，保留private:true，不发布npm或插件市场。

客户端要求DSH **0.2.1-rc.2**、Node **>=24**，构建与CI固定Node24.21.0／pnpm11.7.0及原lockfile。必须配套支持 `humanAuthorization.version:2` 的协作服务；基础协作协议v3、附件扩展v1保持不变。旧peer拒绝请求，不伪造旧授权模板、不降级传输。

## 本版变化

- 在已选协作路线上，自然说明项目及附件用途；首次项目只从授权目录唯一精确匹配，不要求手填ID或旧参数模板。
- 原生文件／图片或明确工作区路径，支持先阅读、后归档、原件仍可靠可用时补答用途。用途不明、多源冲突、原件失效、身份／工作区改变或对象不确定时澄清，不扫描电脑或猜选旧材料。
- 最新内容相同不新增版本；历史内容恢复必须核对资料名、旧版与当前版后确认。新附件／新话题／取消／重建不能静默复活旧许可；引文、文件名、正文、模型回答和只读历史不是操作授权。
- 修复重建后裸确认／“刚才那份”误承接唯一旧回执；明确源与缓存冲突、未知源名称、源／目的资料角色均保守核实，不把另一份文件当作当前对象。
- 当前真人原文与精确v2授权绑定；确定未开始、已核实部分成功和整体未知分开表达。已发送失败仍保留宿主错误状态，不自动重试或重发；整理要点／方案草稿不等于正式登记、批准、激活或完成。

日常示例、格式与原件边界见[附件指南](<ATTACHMENTS.md>)和[README](<../README.md>)。本版不扩审批接口、业务生命周期、通用状态机或原协议版本。

## 验证与验收边界

冻结功能实现已通过离线原默认267例（179单测＋88集成）与detached包267例，以及95个实际hook／解析焦点用例；没有以串行诊断替代默认门禁。覆盖官方Cordis／LLM／Adapter／MemberClient、同sqlite与同login的真实客户端重建、原生／工作区附件、可信回执及中文结果；文件、传输、服务器状态是合成夹具。

此后只变更发行版本与说明，功能七源码保持冻结。PR／main／tag的真实Ubuntu、Windows与Package门禁须通过，Release只能使用原工作流的已验证artifact。三资产是版本化tgz、SHA256SUMS和release.json；应核对release.json的commit／tag／sha256与tag提交和实下载包。固定tag的隔离安装检查不使用desktop／acp／用户main profile，不启动SSH或真实业务。

**本版没有真人GUI、本人钉钉重验或真实模型业务验收结论。** 旧扫码／业务历史验收不替本版背书。服务端部署由独立固定SHA流程负责；客户端由用户自行部署。Git提交、CI或Release成功都不表示当前正在运行的GUI或服务已更新，也不授权重放任何历史消息。
