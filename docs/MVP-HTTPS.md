# 0.6.0 MVP：一个HTTPS地址＋电脑钉钉

状态：服务端正式MVP已切换；A／B实际统一网络通过。A通过官方管理器重装并完整重启后，已在现用GUI本人手动打开电脑钉钉，成功显示陈锦鸿（项目管理员）及7天截止时间；这不等于自动打开已通过。现补[点击登录自动打开修复](<MVP-PC-AUTO-OPEN-2026-10-16.md>)，按用户顺序须先A实测自动打开，再B本人测试，通过后才继续项目与业务。历史[升级混载诊断](<MVP-UPGRADE-2026-10-16.md>)保留。新客户端必须配合同一MVP版本服务器，不能用旧SSH/OAuth后端冒充通过。

## 普通成员

1. 在DSH官方插件管理器安装CI成功固定SHA的客户端插件，**从托盘完整退出DSH后重新打开**并进入现用页面。只关窗口／刷新／停用再启用可能仍复用旧后台模块；看到“后台仍是旧版”时停止连接／登录并完整重启，不导入个人JSON或配置SSH。安装默认启用本机组件，但不会自动连接、登录或调用模型。
2. 打开“设置→协作服务”，输入管理员一次部署好的HTTPS origin（无路径、账号或查询参数），点“保存并连接”。无需个人账号、私钥、JSON导入或hosts修改。
3. 点“电脑钉钉登录”，本机Host向Windows已注册的钉钉协议处理器提交**本次**工作台应用打开请求，无需再点链接。页面显示“已请求打开”只表示系统受理，不等于应用已渲染或身份已确认。端内核对组织、服务和本次请求，再核对实际官方员工身份并确认；原DSH自动领取结果，不用手机扫码或“我已扫码”按钮。
4. 无法自动唤起时，明确点“重新打开电脑钉钉”只重开同一未过期请求，不再创建登录请求；也可在**电脑**钉钉工作台打开同一已发布应用，输入原DSH显示的16位核对码。它只用于绑定这次请求，不是授权码；只使用本人原DSH的码，不接受他人发来的码／链接。
5. 登录后，模型菜单Collaboration分组列出全部项目。新对话明确选项目，已有远端对话固定原项目；普通模型菜单不变。

第一次成功登录由服务端自动登记／复用组织身份。普通成员无须找管理员开通；未登录者不会出现在角色分配候选中。

## 固定管理员

相同地址、相同PC登录流程。仅官方固定管理员比普通成员多“创建项目与角色分配”：创建项目，刷新已登录成员候选，选择项目／职责／人员，明确确认提交。角色换人暂停相关未生效方案，接任者不继承旧同意，需明确修订和重新逐角确认。

没有成员增删、停用／恢复、管理员增减、设备管理或项目访问名单。全员可见不是允许代替职责本人作正式决定。

## 设备登录记忆

- 当前A/B MVP是Windows客户端，用CurrentUser DPAPI加密保存最多7天token；只在当前Windows用户上下文解密。普通配置只含origin／serviceId，SQLite只含设备与会话映射，不含token明文。
- 服务端只保存token散列，7天不随使用延长；多台设备各自登录。“退出当前设备”清除本机密文并在线撤销这个设备，不退出其他设备。
- 不读电脑钉钉本地登录文件。退出钉钉不自动退出本服务，应显式退出本服务。
- 组织资格最多缓存5分钟。官方暂时不可用则业务暂停，不自动延长或废弃7天登录；官方明确离职／不再合格则旧登录失效。
- 其他平台安全存储未验收时明确拒绝，不写明文作为替代。Windows系统保护不可用／密文损坏时清楚报错，不伪装已登录。
- 本机状态位于当前用户 `.dsh/dsh-collaboration-client/https-mvp` 专属目录。旧配置不自动读取／导入，不作为新版本回退。切服前必须先退出，不能把旧身份、会话或附件令牌迁移到另一服务。

## 失败与恢复

没有隐式TLS跳过、HTTP回退或个人SSH连接。域名／证书／WSS不通时报告入口错误；PC钉钉未安装／未登录或应用未发布／PC首页未配置，需修复真实前置，不走手机扫码。

断网只恢复记录与查询状态，从不重发prompt、角色决定或管理操作。结果未知先刷新服务器真实项目／职责；不自动创建第二个项目或再次确认。离线退出会清本机密文，但服务器撤销未确认要明确显示，不能声称旧token已远端作废。
