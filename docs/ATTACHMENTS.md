# 本地附件传输与项目资料归档

## 当前工作区状态与能力边界

本页描述**0.6.2-rc.1自然语言资料MVP**，发行以该固定tag的GitHub Release与CI为准，见[本版说明](<RELEASE-0.6.2-rc.1.md>)。发布不表示当前运行中的插件、GUI或服务已经升级；客户端由用户安装，服务端需配套支持humanAuthorization v2，部署与真人／真实模型验收另行完成。此前客户端0.5.3／服务端0.5.0及DSH0.2.0-rc.2的发行证据仅为历史；当前宿主与构建范围以[README](<../README.md>)为准。

双端必须协商 `humanAuthorization.version: 2`；基础协作协议v3及附件扩展v1不变。不支持的peer会拒绝请求，**不会读取并上传文件后再降级，也不会伪造旧模板或自动重发业务prompt**。离线测试与能力声明不是现实模型、用户GUI或已部署服务验收。

## 日常操作：说用途，不填授权参数

在已选的Collaboration会话中添加聊天文件／图片，或明确选择当前会话工作区内的单个 `@路径`／`@"含空格的路径"`，然后自然说明：

- “请归档这份附件并整理要点。”
- “先阅读，不要归档。”
- “把刚才那份归档。”——先阅读后再授权归档时，先核实同账户／会话／项目的原回执，不自动重传。
- “请把这份文件作为《requirements.md》的新版本归档。”——需要服务端真实资料目录中精确、唯一的目标；不按文件名里的v2等字样猜测。

首次项目尚未绑定时，可说明“这是南航智慧出行数字人POC的需求文档，你需要归档该文档”。只有授权项目目录中唯一精确匹配且当前协作路线／会话状态允许时才保存选择，不按相似名称、参考项目或其他成员选择改绑。

裸附件用途不明先问用途。仍属同一成员、会话、项目和工作区、原件仍可用时，补答“归档刚才那份”即可复用已选opaque引用，无须为了补用途重附；不会扫描电脑。多候选、混合逐份操作、原件失效或身份／工作区变更时先澄清。引用、代码块、标题、文件正文、模型回答及恢复历史本身都不授予操作权限。

文件路径须在**当前本地会话工作区**内，不扫描目录；拒绝工作区外文件、目录、symlink/junction、`.dsh`／`.ssh`／`.git`与常见凭据／私钥路径。不读取文档里提到的其他文件。最多5份文件，单文件与每消息总计20MiB。

## 版本、草稿与真实结果

最新内容相同不新增版本；明确改版追加版本；命中历史旧内容先问是否恢复为新版本。自然答“确认”／“确认恢复”仅适用于当前唯一、可信、未失效的恢复提议；新话题、取消或已消费的确认不能成为永久许可。重启／重建后缺少连续可信的对象上下文时，裸“确认”与“刚才那份”先澄清，不因旧回执恰好唯一就猜选旧资料。可明确资料名称；系统重新展示所指资料的旧版与当前版、询问后，才建立新的确认上下文。未决原件无法可靠识别时需要重新选择，不靠读取旧历史恢复操作许可。并发版本变化仍须重新核实，不靠旧确认覆盖新版。

归档不分配人员、不批准方案、不自动激活或完成任务。分析准备／整理要点／方案草稿不等于正式登记分析；只有实际正式提交成功才宣布登记。文件名中的版本号也不等于资料版本号。

日常结果按资料名、版号说明，不要求复制内部ID、工具JSON或服务器路径。确定“业务未开始”、已核实的部分成功与“整体结果未知”分别表达；已发送失败仍保持宿主错误状态，不用正常完成冒充成功，也不承诺所有宿主状态标记消失。

## 原件、格式与技术传输边界

技术链路仍为 `attachment_transfer → attachment_inspect → attachment_archive`。客户端仅提供当前session/request/opaque句柄授权的文件块；服务端校验hash／长度并保留原件。单个旧回执已归档时返回原版本，不为再次提及而新增版本或擅自恢复历史。

支持DOCX、严格UTF-8 MD/TXT及单帧PNG／JPEG／WebP。**GIF禁止上传**：名称、声明类型与收到字节均校验，改扩展名也拒绝，不提首帧／转码绕过。DOCX只提正文／表格，嵌入图片不自动进入视觉模型。图片是否能被实际模型理解仍取决于已验证的服务端能力，不因传输／归档成功就宣布视觉分析成功。

DSH原生image可能已经归一化，丢失来源时不能从PNG字节识别其曾为GIF；原件保真请使用file附件或明确路径。历史图片仍须当前真人明确用途、核实同账户／会话／项目原件，不以旧历史或模型回答自动重发。

## 断线与只读核实

保留已有本地／远端会话映射，不自动重发旧消息、上传或归档。可只读核实本会话回执、资料版本与项目进度；恢复历史调用不是新的业务授权。收到原件但未归档时，可在同一会话自然说明继续；原件确实不可用才要求重新选择。换账号／会话不能读取别人的接收回执，正式共享资料仍执行原项目权限。
