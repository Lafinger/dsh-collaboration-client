# 接入设置与当前会话项目选择分开

成员连接配置和设备登录归接入设置，项目归属归当前业务对话。用户确认设置侧栏“协作服务”只管理连接与身份；后续[菜单设计确认](<../设计确认-模型菜单项目选择.md>)将独立项目面板与单一“项目选择”项改为Collaboration组内的授权项目行，明确点选同时确定当前对话项目与协作路由，不把项目伪装为底层模型，也不以SSH账号替代钉钉和项目权限。

保存的配置选择优先旧显式配置及有界目录发现，但缺失或改变时不自动换账号；切换需退出且不能正在执行业务，旧映射不迁移、不清空、不重放。这牺牲静默回退的便利，以防跨服务／成员／项目混用，并保留不改现用profile或覆盖配置的用户控制边界。
