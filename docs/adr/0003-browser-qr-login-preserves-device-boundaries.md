# 改用网页扫码，但不回退个人连接配置或清除会话

状态：**已接受：用户最终确认按最小改版方案实施**。用户确认默认浏览器打开钉钉官方授权页、手机扫码后原DSH自动领取；不依赖电脑钉钉／工作台／16位核对码，不内嵌二维码，不增加本应用的第二次确认。保留统一HTTPS、自动登记、7天系统加密设备登录、本机退出、项目菜单和原会话归属，不恢复旧个人SSH／JSON／hosts前置。

切换时旧PC设备资格一次性失效，各设备重扫一次；只清理明确失效的旧登录密文，不删项目映射、私人会话或不重发日志。实际官方授权者决定登录身份，误扫退出重扫，不能将原成员的私人对话改挂给另一个人；手机普通网络和电脑原LAN／ZeroTier回调须实机验证，不暗增公网。该取舍减少操作步骤，但必须以稳定成员与严格原设备绑定换取无额外确认的自动领取，不能因换登录入口弱化隔离。边界见[客户端改版方案](<../MVP-网页扫码登录改版方案.md>)；仅更新[原接入ADR](<0002-mvp-address-and-official-identity.md>)中的PC入口选择，实施按已批准的非破坏性验证、固定CI和真实扫码门槛推进，不立即撤销登录。
